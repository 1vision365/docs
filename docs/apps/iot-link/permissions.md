# Permissions

<!-- agent:begin permissions -->
IoT Link has two permission sets that you can assign to users.

| Permission set | Name | Description |
|---|---|---|
| `1VIS IoT Setup` | 1Vision365 IoT Setup Permissions | For administrators. Gives access to the IoT Setup and the setup wizards, devices, endpoints, routing rules and the provisioning log. |
| `1VIS IoT User` | 1Vision365 IoT User Permissions | For users who work with IoT data. Gives access to the IoT Hub Events, devices (read only) and the heartbeat. |

Every license plan includes both permission sets.
