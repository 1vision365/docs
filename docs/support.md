# Support

## How to get help

1. **Check this documentation site** — installation, configuration and known issues are covered here first.
2. **Search or open an issue** in the public support repository: [github.com/1vision365/support](https://github.com/1vision365/support). Pick **Bug**, **Question** or **Feature request**.
3. An automated assistant may reply first, from our public documentation. A team member takes over when the assistant can't help, or when the question needs a person (for example pricing or anything specific to your environment).

Include in every request: app name, app version, Business Central version, and a short description of the problem.

Do not post passwords, API keys, tokens, tenant IDs, environment URLs, or customer/supplier/employee data in an issue — the support repository is public.

Found a security vulnerability? Do not open a public issue. Use the **Security** tab of the [support repository](https://github.com/1vision365/support) to report it privately.

**Official support address:** [info@1vision365.com](mailto:info@1vision365.com).
