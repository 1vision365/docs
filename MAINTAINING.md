# Maintaining the docs

Notes for maintainers of this repository. The customer-facing overview is in [README.md](README.md).

The site is a MkDocs Material site, deployed to GitHub Pages at <https://docs.1vision365.com/>.

## Local preview

Double-click `serve.cmd`, or run `.\serve` in PowerShell. The first run creates a `.venv` and installs the requirements. Then it opens http://127.0.0.1:8000 and refreshes when you save a file. Stop with `Ctrl+C`.
